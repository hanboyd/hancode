# ADR 004：中文 2/3-gram 搜索

状态：接受。

连续汉字按 Unicode rune 生成 2-gram 与 3-gram；单汉字查询保留一个单 rune token。英文单词和数字按 Unicode 边界提取并小写，因此支持中英文混合、英文大小写不敏感和数字搜索。

2-gram 提高短中文词召回，3-gram 降低常见双字噪声，代价是辅助 token 表比正文索引更大。查询后必须回到索引保存的原始标题、路径、标签和正文验证；精确短语要求连续子串匹配，避免 N-gram 假阳性。

排名权重为标题 5、标签 4、路径 3、正文 1，并叠加命中 token 数；同分按规范路径排序以保证分页稳定。Tokenizer 有独立版本，可在未来替换为 FTS5 trigram 或成熟中文分词器。
