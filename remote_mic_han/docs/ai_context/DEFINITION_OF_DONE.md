# Definition of Done

A task is complete only when all applicable items are true:

- Scope and non-goals are explicit.
- Relevant build, tests, and diagnostics were actually run.
- Failure and recovery paths are documented.
- No unrelated user changes were overwritten.
- Documentation matches observed behavior.
- Hardware/system boundaries are marked `passed`, `failed`, `deferred`, or `not_applicable`.
- `CURRENT_STATUS.md` and `AI_HANDOVER.md` are updated before a model switch.
- Remaining risk and the next executable step are recorded.
